# CorzClient

CorzClient — a premium Fabric utility client for Minecraft 1.21.11.

## Features

- Utility modules and QoL tweaks
- Cosmetics system
- Configurable HUD

## Building

> **Note:** the public repository does not include the internal `corz-core`
> and `corz-cosmetics` modules (hosted on our private Maven). A full build
> therefore requires access to the private repository — use the prebuilt
> release jar instead.

Requirements: JDK 21+

```bash
./gradlew build
```
