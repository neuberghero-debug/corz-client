A Fabric/Forge mod for Minecraft [Version].

Installation

Drop the jar into your mods folder.

Building from source

```bash
git clone https://github.com/yourname/yourrepo.git
cd yourrepo
./gradlew build
```

Note: The Gradle wrapper and some dependency versions in this repo are outdated and not easily fixable without a full rebuild setup. Building from source will fail as-is.
